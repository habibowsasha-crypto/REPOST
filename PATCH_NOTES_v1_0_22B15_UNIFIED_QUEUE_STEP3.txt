TgBlaster v1.0.22b15 — Общая очередь, Шаг 3 (UI + статистика + пауза)
====================================================================

Основа: v1.0.22b14 (рабочая unified-отправка).

Что добавлено
-------------
1. Экран «🌐 Режим очереди DM»:
   - текущий режим;
   - активные / готовые / reserved лиды;
   - разбивка статусов;
   - сколько лидов с preferred-аккаунтом на PeerFlood-паузе;
   - текущая общая пауза и время до следующего слота.

2. Безопасное переключение режима:
   - кнопка ведёт на подтверждение;
   - данные пула не удаляются при возврате «по аккаунтам».

3. Настройка общей паузы:
   - пресеты: 30–60 сек, 60–120 сек, 2–5 мин, 5–10 мин;
   - ручной ввод «мин макс» в секундах;
   - значение пишется в dm_queue_runtime и сразу используется в unified mode.

4. unified_queue_stats() для админского снимка пула.

Не изменено
-----------
- first_message / VIP Кирилла / kirill_vip_funnel
- логика send pipeline Step 2
- SpamBot monitor

Новых Variables нет.
