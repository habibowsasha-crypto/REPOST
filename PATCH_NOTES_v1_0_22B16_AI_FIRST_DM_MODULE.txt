TgBlaster v1.0.22b16 — модуль «🤖 AI Первый DM»
===============================================

Основа: v1.0.22b15

Что добавлено
-------------
Отдельный выбираемый модуль первого DM:

- 🧩 Текущие фразы — как раньше
- 🤖 AI Первый DM — NEW
- 👑 VIP Кирилла — без изменений
- 🤖 AI Быстрый оффер — без изменений (AI после ответа)

Поведение AI Первый DM:
1. Перед отправкой OpenAI генерирует одно короткое сообщение.
2. Без ссылок, без оффера, без обещаний прибыли.
3. Антиповтор по последним ~40 текстам.
4. До 3 попыток генерации; иначе локальный fallback из мягких/trading фраз.
5. Требует OPENAI_API_KEY для AI; без ключа всегда fallback.
6. Опционально AI_FIRST_DM_MAX_TOKENS (default 120).

Где переключать:
- создание DM-задачи (выбор модуля);
- карточка задачи → «Изменить модуль первого DM».

Не изменено побайтово:
- services/first_message.py
- services/first_message_kirill_vip.py
- services/kirill_vip_funnel.py
