CHANNEL DM BOT PATCH REPORT v1.0.78

STATUS
- Corrected candidate built after an independent re-audit of v1.0.77.
- Built strictly from v1.0.77.
- Production Telegram delivery was not executed locally.

WHY THIS PATCH WAS REQUIRED
- v1.0.77 correctly removed AI from short_hook and moved generation after entity resolution.
- Independent verification found two uncovered edge cases.
- An account that observed a target without a stored access_hash was excluded before its safe local Telegram cache could be checked.
- Identical hashless activity could reopen a no-entity terminal lead, especially when multiple known accounts alternated activity.

IMPLEMENTED CHANGES
1. Hashless observing account support
- Account-owned evidence is now considered ownership even when access_hash is absent.
- Such an account receives exactly the normal local numeric-cache resolution path.
- Automatic remote username lookup remains disabled.
- A successful local cache result stores the recovered access_hash for later direct use.

2. Stable negative cache
- A terminal no-entity lead reopens only when account-owned evidence actually improves.
- Repeated identical activity from the same account does not reopen it.
- Alternating identical hashless activity from multiple already-known accounts does not reopen it.
- A newly available or changed access_hash still reopens the lead correctly.

3. Preserved v1.0.77 fixes
- Entity is resolved before First DM generation.
- short_hook never calls AI.
- Leading AI list markers cannot reach Telegram.
- Automatic username search remains disabled.
- Account-owned access hashes remain isolated per sender.
- Bounded recent-history sync remains unchanged.
- Reauthorization-required accounts remain excluded.

UNCHANGED
- Promo and channel link behavior
- Calm refusal and aggressive opt-out rules
- Apology and link help timers
- Dialog account ownership
- Global and account pacing
- Daily limits
- PeerFlood and SpamBot logic
- Maximum outgoing message budget
- magnet, short_hook and legacy modes

TEST RESULT
- Full pytest result: 271 passed.
- Dedicated v1.0.78 edge-case suite: 6 passed.
- Clean extraction release gate: passed.
