CORE PRODUCT RULES
- Monitor selected Telegram chats through authorized user accounts.
- Build one shared lead queue.
- Prefer the account that actually saw the user.
- Never transfer an active dialog to another account.
- Send First DM only when global and account pacing allow it.
- After an allowed response, send the exact configured channel link in promo.
- Send apology after 60 seconds.
- Send separate link-opening help after another 60 seconds.
- Only rude text, aggression, threats, insults or explicit requests not to write create terminal stop and global opt-out.
- Calm refusal may continue the promo branch.
- Any non-text response is neutral or positive and continues the approved branch.
- Standard outgoing budget is 4, absolute maximum is 5.
- At most one optional Q&A may be used without displacing mandatory steps.
- Only First DM may contain a greeting.
- Use only the short ASCII hyphen in project text.

FIRST DM MODES
- magnet: reviewed concrete trader questions.
- short_hook: reviewed short questions and requests for help with a question. No AI call.
- legacy: previous neutral pool for rollback.
- Invalid FIRST_DM_STYLE fails closed.
- All modes use the global last-20 uniqueness rule.
- Maximum AI regeneration attempts remain 2 where AI is enabled.
