TgBlaster v1.0.22b6 — карточки лидов и стабильные пачки очереди

База:
- TgBlaster v1.0.22b5.

Добавлено:
- до 25 лидов в одной пачке для /dm_queue TASK_ID;
- карточка каждого лида: @username/имя, полный Telegram ID, ссылка на исходное сообщение, исходный чат;
- кнопки «Следующие 25», «Предыдущие 25», «Обновить текущие», «С начала / обновить список»;
- снимок ID очереди на время просмотра, исключающий повтор и пропуск позиций при параллельной отправке DM;
- сохранение source_chat_username и source_message_id для новых записей очереди;
- ссылки t.me для публичных и закрытых супергрупп;
- безопасная миграция старой SQLite-базы.

Поведение:
- /dm_queue 25: 25 — ID DM-задачи, а не количество лидов;
- повторная команда создаёт новый снимок и снова начинает с первых 25;
- «Следующие 25» показывает следующую пачку исходного снимка без повторов и сдвигов;
- «Обновить текущие» не подмешивает новых людей, а обновляет статус открытой пачки;
- «С начала / обновить список» включает новые поступления в очередь.

Совместимость:
- существующая очередь не очищается;
- для записей до v1.0.22b6 source_message_id отсутствует, поэтому переход к старому сообщению недоступен;
- новые записи получают кликабельный переход автоматически;
- очередь, dispatcher, first DM, AI-воронки, completed и opt-out не изменены.

Первый DM:
- services/first_message.py не изменён;
- services/first_message_kirill_vip.py не изменён;
- services/kirill_vip_funnel.py не изменён.
